## 📋 Sobre a Plataforma

O desperdício de alimentos é um desafio presente na rotina de muitas escolas. Foi a partir dessa realidade que nasceu o **Reali**, uma plataforma que une tecnologia, educação e sustentabilidade para transformar a gestão da alimentação escolar.

Por meio da análise de dados, buscamos ajudar as escolas a compreender o consumo de alimentos, identificar desperdícios e aprimorar o planejamento das refeições, contribuindo para um futuro mais consciente e sustentável.

> "Mais controle, Menos desperdício"🍃

## 🎯 Diretrizes Estratégicas

O **Reali** nasceu durante o **Projeto Demoday do Instituto PROA**. Identificamos em uma pesquisa a comida em excesso que era descartada, desenvolvemos uma solução para mitigar esse processo e ajudar o meio ambiente.

### Missão
Reduzir o desperdício alimentar com dados e tecnologia.

### Visão
Ser referência em gestão alimentar sustentável. 

### Valores
* **Sustentabilidade** 
* **Inovação**
* **Responsabilidade Social** 
* **Colaboração**

## 🛠️ Tecnologias Utilizadas

O ecossistema técnico do projeto foi construído com foco em escalabilidade e performance:

* **Front-end:** React Native | Expo | TypeScript
* **Back-end:** Python | Django | Django REST Framework | Flask | APIs REST.
* **Banco de dados:** PostgreSQL
* **Inteligência artificial e Visão Computacional:** Agno | Gemini API | Ollama | YOLO | ByteTrack
* **Design & Prototipagem:** [Figma](https://www.figma.com/design/ysr6QQkoW6pyIeqRFMKdlP/Reali?node-id=0-1&t=zdcrA6rXFZBxejUb-1)
* **Estilização:** TypeScript | StyleSheet (React Native)
* **Versionamento:** Git & GitHub
